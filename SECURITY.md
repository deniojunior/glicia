# Política de segurança

Não publique vulnerabilidades, chaves de API, dados de saúde ou falhas que possam causar uma sugestão clínica perigosa em issues públicas.

Reporte privadamente ao mantenedor pelo recurso **Security Advisories** do repositório GitHub. Inclua passos de reprodução, impacto e versão afetada. O projeto não oferece garantia de tempo de resposta, mas buscará reconhecer o reporte e avaliar uma correção responsável.
