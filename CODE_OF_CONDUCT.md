# Código de conduta

Esperamos uma comunidade respeitosa, inclusiva e colaborativa. Assédio, discriminação, ataques pessoais e divulgação de informações privadas não são aceitos.

Para reportar uma violação, use o canal privado indicado em [SECURITY.md](SECURITY.md). O mantenedor avaliará o caso com discrição e poderá remover conteúdo ou participação que viole este código.
