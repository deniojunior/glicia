# Glicia v0.4.0-alpha

Data: 2026-08-30

## Resultado

O PWA agora pode ser configurado inteiramente pelo celular: chave OpenAI transitória, cinco RICs,
modo de interação e modelo. Preferências e progresso do onboarding ficam no IndexedDB; a chave
nunca é persistida e deve ser informada novamente ao recarregar.

## Incluído

- Onboarding retomável e bloqueio claro quando faltar chave na sessão.
- Configurações visuais para RICs, modo e modelo.
- Conversa ligada ao adaptador OpenAI Responses quando uma chave transitória existe.
- Tabela nutricional da CLI incluída nas instruções do adaptador web.
- Interface principal simplificada para mostrar apenas a próxima ação.

## Impacto

Uma pessoa pode concluir a configuração inicial no celular sem editar arquivos. A chave continua
somente na sessão atual e precisa ser fornecida novamente depois de recarregar a página.

## Limitações conhecidas

- A chamada direta do navegador para OpenAI depende de compatibilidade/CORS e deve ser validada
  manualmente com uma chave de teste; nenhuma chave foi usada na CI.
- O cálculo local de dose, confirmação clínica completa, memória alimentar persistente, histórico
  e backup pertencem aos próximos marcos.
- Não armazene a chave em um dispositivo compartilhado. O PWA não é dispositivo médico.

## Verificação

Em `apps/pwa`, execute `npm ci`, `npm run lint`, `npm run typecheck`, `npm test` e `npm run build`.
