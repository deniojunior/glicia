# Glicia v0.5.0-alpha

Data: 2026-08-30

## Resultado

O fluxo PWA agora conclui uma refeição com confirmação, travas locais, cálculo determinístico,
registro opcional da dose aplicada e histórico local.

## Incluído

- Cálculo local após confirmação explícita, com RIC por tipo de refeição e arredondamento final.
- Bloqueio abaixo do limite de hipoglicemia e aviso de queda rápida abaixo de 100 mg/dL.
- Memória alimentar confirmada persistida no dispositivo.
- Histórico imutável com entrada, resumo, parâmetros, cálculo e dose aplicada opcional.
- Consulta local de histórico em ordem recente.

## Impacto

O PWA passa a cobrir o fluxo funcional central da CLI no celular: confirmar dados, aplicar as
travas e o cálculo local e, opcionalmente, registrar a dose aplicada.

## Limitações conhecidas

- A chamada direta para OpenAI ainda requer validação manual em navegador com uma chave de teste.
- Não há exportação, importação, backup ou sincronização nesta versão; eles são o foco de v0.6.
- Nenhuma credencial entra no histórico ou na memória persistida.

## Verificação

Em `apps/pwa`, execute `npm run lint`, `npm run typecheck`, `npm test` e `npm run build`.

## Próximo passo

A `v0.6.0-alpha` adicionará exportação, importação, backup local e instalação orientada.
