# Glicia v0.6.0-alpha

Data: 2026-08-30

## Resultado

A PWA passa a preservar e transportar seus dados locais: backup manual, importação validada e
instalação orientada no celular, sem incluir a chave OpenAI.

## Incluído

### Portabilidade local

A PWA passa a oferecer backup manual em **Configurações → Seus dados**. O arquivo JSON inclui
preferências clínicas, modo, provedor/modelo, memória alimentar e histórico de refeições. Cada
arquivo informa a versão do schema, a versão da aplicação e a data de exportação.

A chave OpenAI não é persistida e não faz parte do backup.

### Importação segura

Antes de gravar, a Glicia valida o arquivo inteiro e mostra quantas refeições e itens de memória
serão restaurados. A ação é uma substituição total, confirmada pela pessoa usuária. Imediatamente
antes dela, a aplicação tenta baixar uma cópia automática do estado atual para permitir recuperação.

Arquivos de versão futura, JSON inválido, parâmetros inválidos e registros duplicados são
recusados sem alterar os dados locais.

### Instalação e uso offline

No primeiro acesso, navegadores compatíveis mostram o botão de instalação. No iPhone, a Glicia
explica o caminho pelo Safari: **Compartilhar → Adicionar à Tela de Início**. A instalação depende
do navegador e não é automática.

O app shell é armazenado para abrir a interface sem rede. A conversa com a IA continua precisando
de conexão; a versão alpha ainda não apresenta um fluxo de contingência manual.

## Impacto

É possível levar configurações, memória alimentar e histórico para outro aparelho usando um
arquivo local. A importação substitui o conjunto local somente após uma confirmação explícita e
mantém a chave fora dos dados restaurados.

## Limitações conhecidas

- A importação desta versão substitui todos os dados; não há mesclagem entre backups.
- A cópia automática depende de o navegador permitir o download iniciado durante a restauração.
- A restauração entre dispositivos e navegadores reais precisa da validação manual prevista para a beta.
- O build continua emitindo aviso de bundle acima de 500 kB pela tabela nutricional incluída.

## Verificação

Em `apps/pwa`, execute `npm run lint`, `npm run typecheck`, `npm test` e `npm run build`. Para a
CLI, execute os comandos de qualidade em `docs/desenvolvimento.md`.
