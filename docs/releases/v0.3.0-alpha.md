# Glicia v0.3.0-alpha

Data: 2026-08-30

## Resultado

Esta versão entrega o primeiro protótipo PWA mobile-first da conversa da Glicia. A CLI continua
sendo a interface funcional de referência para configuração e cálculo completo.

No PWA, a pessoa pode enviar em uma única mensagem o alimento, a glicemia, a tendência e o tipo
de refeição; revisar a resposta estruturada; corrigir; confirmar; e iniciar outra refeição. A
demonstração local não transmite dados.

## Incluído

- Manifesto, ícones e service worker para instalação como PWA.
- Sessão conversacional isolada do React, com modos Preciso e Rápido fixos durante a refeição.
- Domínio TypeScript em conformidade com as fixtures compartilhadas da CLI.
- Adaptador OpenAI Responses separado da interface: JSON Schema estrito, `store: false`,
  continuidade via `previous_response_id` interna e erros classificados.
- Markdown comum nas respostas da IA, com HTML bruto descartado antes de chegar ao DOM.
- Tela de erro recuperável: o texto em edição permanece no compositor para reenvio.

## Impacto

A CLI permanece como referência para configuração e cálculo completo. Esta versão adiciona a
primeira interface de celular sem mudar as regras clínicas nem exigir uma chave OpenAI no PWA.

## Limitações conhecidas

- O app abre usando um provedor de demonstração; não há campo de chave, RICs nem cálculo de dose
  na web nesta versão.
- O adaptador OpenAI é validado por testes de contrato, mas não é ligado à interface até o
  onboarding/BYOK do `v0.4.0`. Assim nenhuma chave é solicitada, gravada ou enviada pelo PWA.
- A chamada direta de navegador para o provedor precisa ser testada com uma chave real temporária
  após a tela de configuração existir; se não for viável, a decisão sobre proxy opcional será
  registrada antes de publicação ampla.
- O PWA não é dispositivo médico e não substitui a revisão da pessoa ou da equipe de saúde.

## Verificação

Execute, a partir de `apps/pwa`:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

E, para a CLI, siga os comandos de qualidade em `docs/desenvolvimento.md`.

### Validação manual no celular

1. Em `apps/pwa`, execute `npm run dev -- --host`.
2. Abra a URL exibida em um celular na mesma rede e envie uma mensagem completa, por exemplo:
   `arroz, frango e salada; 120 mg/dL, seta estável, almoço`.
3. Confira o resumo, faça uma correção e confirme os dados.
4. Use “Iniciar nova refeição”, instale pelo menu do navegador e repita o fluxo após reabrir.
5. Desative a conexão e envie uma mensagem para conferir o aviso e que o texto continua no campo.
