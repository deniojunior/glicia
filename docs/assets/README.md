# Assets de demonstração

Esta pasta guarda os arquivos de demonstração do Glicia.

- `glicia-demo.cast`: gravação reproduzível do terminal no formato Asciinema.
- `glicia-demo.gif`: versão em GIF da demonstração, exibida no README.

Use somente dados fictícios. Nunca grave ou publique chaves de API, glicemias reais, refeições reais, histórico local ou qualquer outro dado de saúde identificável.

O GIF é exibido na seção **Demonstração** do `README.md`.
